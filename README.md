# 🛍️ E-Commerce Website (Clothing Store)

An online clothing store that provides a smooth shopping experience with modern UI, powerful filters, and a secure checkout system.

---

## 🚀 Features

- 👕 **Product Categories**: Men, Women, Kids  
- 🛒 **Add to Cart / Remove from Cart**  
- 💳 **Secure Checkout** (Cash on Delivery / Online Payment Integration)  
- 🔍 **Dynamic Search & Filters** (Men,wome,kids,Topwear,Bottomwear,Winterwear)  
- 🏷️ **Discounts & Offers**  
- 📱 **Responsive Design** (Desktop, Tablet, Mobile)  
- 🔐 **User Authentication** (Signup / Login with JWT)  
- 📦 **Order Tracking**  

---

## 🖥️ Tech Stack

### Frontend
- React.js / Next.js  
- TailwindCSS for styling  
- Axios for API calls  


### Backend
- Node.js + Express.js  
- MongoDB (Mongoose ORM)  
- JWT Authentication  
- Cloudinary for image uploads  

### Deployment
- Frontend: Vercel / Netlify  
- Backend: Render / Heroku  
- Database: MongoDB Atlas  

---


## ⚡ Installation & Setup

1. Clone the repository:
  
   git clone https://github.com/harini-honey7/E-commerce.

2. Navigate to project folder
    cd/admin
    cd/backend
    cd/frontend

4. Install dependencies:

npm install


5. Start development server:

## for frontend--- npm run dev
## for backend --- npm run server
